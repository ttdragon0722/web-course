認識 Tailwind CSS

Utility-First 的 CSS 框架 —— 不取 class 名稱，直接在 HTML 上組合樣式。

傳統 CSS（要切換檔案）

/* style.css */
.card {
  display: flex;
  align-items: center;
  gap: 16px;
  padding: 24px;
  background: #fff;
  border-radius: 8px;
}

<!-- index.html -->
<div class="card">...</div>

Tailwind（直接寫在 HTML）

<div class="flex items-center
  gap-4 p-6 bg-white
  rounded-lg">
  ...
</div>
  • 改樣式不用切到 CSS 檔，直接在元素上調
  • class 名稱「望文生義」，看了就懂
  • 不用再煩惱命名

變數 — const 與 let

變數就是「幫資料取一個名字」，方便之後重複使用。

關鍵字特性什麼時候用
const常數，宣告後不可重新指派預設都用它 —— 值不會變的資料
let變數，之後可以改值計數器、會被更新的狀態
 
const name = "Rex";   // 之後不能再改
let count = 0;        // 之後可以 count = count + 1
count = count + 1;

早期還有 var，但現在幾乎不用 —— 記得 const 與 let 就好。

切換狀態的方法

「切換」的核心：判斷現在是開還是關，再做相反的事。

上面這串「判斷 → 加 / 移除」，JavaScript 用一行 classList.toggle() 就能完成。
05 · 實作
05 · 實作

動手寫：Menu 切換 function

把「加 / 移除 class」的操作，全部寫進這段程式碼裡。

// 1. 抓到按鈕和選單兩個元素
const btn  = document.querySelector("#menu-btn");
const menu = document.querySelector("#menu");

// 2. 監聽按鈕的點擊事件
btn.addEventListener("click", () => {
  menu.classList.toggle("hidden");     // 有就移除、沒有就加上 → 切換顯示
  btn.classList.toggle("is-active");  // 順便讓按鈕也變化
});
classList.toggle() —— 有就移除、沒有就加上，一行搞定切換，不用自己寫 if / else。
