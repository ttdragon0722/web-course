01 · HTML 結構

看懂 HTML 結構

HTML 是一棵樹：所有標籤層層包覆，有上下層關係。

  • <head>　給瀏覽器看的設定（標題、CSS 引入），使用者看不到
  • <body>　使用者真正看到的所有內容
  • 父層包子層，縮排就是「層級關係」的視覺呈現
html
├── head          # 給瀏覽器看的設定
│   ├── title
│   └── link          # CSS 引入
└── body          # 使用者看到的內容
    ├── header
    ├── main
    │   ├── section
    │   └── article
    └── footer

<head> 是什麼？

<head> 是「給瀏覽器看的設定」—— 使用者看不到，卻決定頁面怎麼載入、怎麼被搜尋。

  • <script>　載入 JavaScript，賦予頁面互動行為（常加 defer 或放結尾）
  • <link>（CSS）　引入外部樣式表，決定頁面長相
  • CDN（函式庫）　用網址直接載入第三方函式庫（jQuery、Bootstrap…），免下載
  • 預載圖片　preload 先抓重要資源，畫面顯示更快
  • SEO（meta）　<title>、<meta> 設定標題與描述，給搜尋引擎與分享預覽看
<head>
  <meta charset="UTF-8">
  <title>網站標題</title>   # SEO 標題
  <meta name="description">  # SEO 描述
  <link rel="stylesheet">  # 載入 CSS
  <link rel="preload">     # 預載圖片
  <script src="cdn...">     # CDN 函式庫
</head>

SEO 是什麼？

SEO（Search Engine Optimization，搜尋引擎最佳化）
讓你的網頁在 Google 搜尋結果「排得更前面、被更多人看到」的一整套做法。

01
被搜尋到
用對語意標籤與關鍵字，讓 Google 正確收錄、理解你的內容。
02
排名更前
結構清楚、載入快、行動裝置友善，搜尋名次往前，自然流量變多。
03
點擊更高
好的標題與描述（meta），讓人在結果頁就想點進來。

不用花錢買廣告，靠「把網頁寫對」就能帶來長期流量。　範例參考：ttdragon0722.github.io/ClassSchedule

<body> 是什麼？

<body> 是「使用者真正看到的一切」—— 文字、圖片、按鈕、版面，全部都在這裡。

  • 語意骨架　<header> <nav> <main> <footer> 撐起頁面結構
  • 內容　標題 <h1>、段落 <p>、圖片 <img>、連結 <a>
  • 互動　<button> 按鈕、<form> <input> 表單
  • <script> 也常放在 body 結尾，等內容載入完再執行
<body>
  <header>...</header>   # 頁首 / 導覽
  <main>
    <section>...</section>  # 主要內容
    <article>...</article>  # 獨立區塊
  </main>
  <footer>...</footer>   # 頁尾
  <script src="app.js">
</body>

語意化標籤 vs 非語意化標籤

同樣是容器，差別在「有沒有告訴機器這塊是什麼」。

語意化標籤 — 有意義
<header><nav> <main><article><footer>
標籤本身就說明了用途，對 SEO 友好、無障礙閱讀器也讀得懂。
非語意化標籤 — 純排版
<div><span>
沒有任何語意，只是個盒子。機器不知道裡面裝的是導覽列還是廣告。
為什麼重要：Google 爬蟲靠語意標籤理解網頁內容 — 用對標籤，等於主動告訴搜尋引擎你的網頁在講什麼。

classid

03 · Class & ID

Class vs ID — 實際用法

記住一句話：class 是「分類」，id 是「身分證」。

<!-- 好的用法 -->
<div class="card">...</div>
<div class="card">...</div>   <!-- class 可以重複 -->
<nav id="main-nav">...</nav>  <!-- id 用在唯一元素 -->
  • 同一種樣式套在很多元素 → 用 class
  • 整頁只有一個、要給 JS 抓取操作 → 用 id

04 · data 屬性

data-* 屬性

自定義資料屬性，讓 HTML 攜帶資料供 JS 讀取。

HTML — 把資料掛在標籤上

<button
  data-product-id="42"
  data-action="add-to-cart">
  加入購物車
</button>

JS — 用 dataset 讀回來

// JS 讀取
const btn = document
  .querySelector('button');

btn.dataset.productId;  // "42"
btn.dataset.action;     // "add-to-cart"
使用場景：不想為了傳資料而多一個隱藏 input — 直接把資料寫在元素上最乾淨。
