## 2. 看懂 HTML 結構（01 · HTML 結構）

- 核心比喻：HTML 是一棵**樹**，所有標籤層層包覆，有上下層關係
- 重點：
  - `<head>`：給瀏覽器看的設定（標題、CSS 引入），使用者看不到
  - `<body>`：使用者真正看到的所有內容
  - 父層包子層，縮排就是「層級關係」的視覺呈現
- 視覺：html → head / body 樹狀圖

## 4. SEO 是什麼？（01 · HTML 結構）

- 定義：SEO（Search Engine Optimization，搜尋引擎最佳化）
  - 讓網頁在 Google 搜尋結果「排得更前面、被更多人看到」的一整套做法
- 三個面向：
  1. **被搜尋到** — 用對語意標籤與關鍵字，讓 Google 正確收錄、理解內容
  2. **排名更前** — 結構清楚、載入快、行動裝置友善，名次往前、流量變多
  3. **點擊更高** — 好的標題與描述（meta），讓人在結果頁就想點進來
- 結語：不用花錢買廣告，靠「把網頁寫對」就能帶來長期流量

## 3. 語意化標籤 vs 非語意化標籤（01 · HTML 結構）

- 一句話：同樣是容器，差別在「有沒有告訴機器這塊是什麼」
- 語意化標籤（有意義）：`<header>` `<nav>` `<main>` `<article>` `<footer>`
  - 標籤本身說明用途，對 SEO 友好、無障礙閱讀器讀得懂
- 非語意化標籤（純排版）：`<div>` `<span>`
  - 沒有語意，只是個盒子，機器不知道裡面裝什麼
- 為什麼重要：Google 爬蟲靠語意標籤理解網頁內容


## 5. 核心標籤介紹（02 · 核心標籤）

- **區塊元素（Block）** — 佔滿整行，自己另起一行
  - `<div>` 通用容器（無語意）
  - `<p>` 段落
  - `<h1>~<h6>` 標題層次
  - `<section>` 邏輯區塊
  - `<article>` 獨立內容（文章、卡片）
  - `<ul><ol><li>` 清單
- **行內元素（Inline）** — 跟著文字流動，不換行
  - `<span>` 通用行內容器
  - `<a>` 超連結
  - `<strong>` 粗體（語意：重要）
  - `<em>` 斜體（語意：強調）
  - `<img>` 圖片

## 7. Query: Class vs ID（03 · Class & ID）

- 一句話：兩者都用來「標記元素」，但定位完全不同

| | `class` | `id` |
|---|---|---|
| 用途 | 樣式、重複元素 | 唯一識別、JS 操作 |
| 可重複 | ✅ 一頁可多個 | ❌ 一頁只能一個 |
| CSS 選擇器 | `.card` | `#navbar` |
| 優先度 | 低 | 高（盡量少用來寫樣式） |

---

## 8. Class vs ID — 實際用法（03 · Class & ID）

- 記住一句話：**class 是「分類」，id 是「身分證」**
- 範例：
  - `class="card"` 可以重複套在多個元素
  - `id="main-nav"` 用在唯一元素
- 判斷原則：
  - 同一種樣式套在很多元素 → 用 `class`
  - 整頁只有一個、要給 JS 抓取操作 → 用 `id`

---

## 9. `data-*` 屬性（04 · data 屬性）

- 定義：自定義資料屬性，讓 HTML **攜帶資料**供 JS 讀取
- HTML 端：把資料掛在標籤上
  - `data-product-id="42"` `data-action="add-to-cart"`
- JS 端：用 dataset 讀回來
  - `btn.dataset.productId` → `"42"`
  - `btn.dataset.action` → `"add-to-cart"`
- 使用場景：不想為了傳資料多一個隱藏 `input`，直接把資料寫在元素上最乾淨
