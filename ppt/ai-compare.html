四大 AI 一覽

同樣都是聊天式 AI，但背後的公司、定位與性格截然不同。

產品 開發者 定位 最擅長
ChatGPT OpenAI 全能型通用助手 生態最大、上手最快、樣樣都行
Gemini Google DeepMind 多模態 × Google 生態 超長文件、搜尋整合、影音生成

02 · ChatGPT

ChatGPT

OpenAI · 2022 年底問世
代表模型GPT-5 系列（含 mini / nano）
強項通用問答、多模態、語音對話
特色功能記憶、Canvas、GPTs、深度研究
定價免費版＋Plus / Pro / Team 訂閱
一句話最大眾、最安全的第一選擇

為什麼大家先想到它

  • 使用者與外掛生態最龐大，遇到問題最好查
  • 文字、圖像、語音、檔案一站式整合
  • 深度研究能自動上網查證、產出長篇報告
  • 可建立自訂 GPTs 打造專屬小助手

優勢

  • 通用能力均衡
  • 新手最易上手
  • 生態與資源最多

取捨

  • 進階功能要付費
  • 長文不如對手穩
02 · ChatGPT
03 · Gemini

Gemini

Google DeepMind
代表模型Gemini 2.5 / 3 系列（Pro · Flash）
強項超長 context、原生多模態
特色功能整合搜尋、Workspace、Veo 影片
定價免費版＋AI Pro / Ultra 訂閱
一句話Google 生態裡的萬能放大鏡

它的獨門武器

  • 可一次吞下整本書／數小時影片（百萬 token 級）
  • 原生看懂文字、圖片、音訊、影片
  • 直接接 Gmail / Docs / 搜尋，查最新資料
  • 生圖（Imagen）、生影片（Veo）一條龍

優勢

  • 長文件分析無敵
  • 連動 Google 服務
  • 多模態最完整

取捨

  • 回答風格較不穩
  • 最強功能綁 Google 帳號
03 · Gemini
04 · Claude

Claude

Anthropic
代表模型Claude Opus 4.8 · Sonnet 4.6 · Haiku 4.5
強項長文寫作、程式碼、推理
特色功能Artifacts、MCP、Claude Code
定價免費版＋Pro / Max 訂閱、API
一句話寫作與工程師最愛的職人型 AI

它為什麼受專業使用者偏好

  • 文風自然、長文邏輯連貫，最像「會寫字的人」
  • 程式能力頂尖，Claude Code 可在終端機自主開發
  • Artifacts 即時產生可預覽的網頁／元件
  • 以安全與誠實為設計核心，較少胡亂編造

優勢

  • 寫作品質最佳
  • 編碼能力頂尖
  • 回答穩定可靠

取捨

  • 無原生生圖／影片
  • 台灣知名度較低
04 · Claude
05 · Codex

Codex

OpenAI · 編碼代理
類型自主編碼 Agent（非聊天助手）
底層模型GPT-5 系列之程式特化版
運作方式雲端沙箱 / CLI，自動跑任務
產出直接改檔、跑測試、開 Pull Request
一句話不是陪你聊，是替你寫程式

它和前三者哪裡不同

  • 給它一個任務，它能自己讀程式碼、改、測試
  • 在隔離沙箱中執行，平行處理多個任務
  • 整合 GitHub，完成後直接送出 PR
  • 對標 Claude Code，是「AI 工程師」之爭

優勢

  • 自動化開發流程
  • 可平行多任務
  • 省下重複工

取捨

  • 僅適合寫程式
  • 需要技術背景
